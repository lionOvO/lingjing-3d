# 全 3D 云山浮岛首页

实施：2026-10-26，收尾验收：2026-10-27。

## 用户确认的方向

首页成为完整的 3D 场景，采用场景式探索：拖动环绕浮岛，点击建筑或物件进入功能。沿用云山造物台的青蓝、玉绿、暖金美术方向，主展品为完成度较高的古建筑。

## 实现与入口

- `frontend/src/components/CloudWorldHome.vue`：全屏场景、相机、地点标签、聚焦介绍、跳转、昼夜、动态开关及生命周期清理。
- `frontend/src/utils/cloudWorld.ts`：真实几何浮岛、山体、松树、木桥、云团、水池、锦鲤、铃铛、灵感灯和交互动画。
- `frontend/src/styles/cloud-world.css`：桌面和手机布局、键盘焦点及减少动态效果支持。
- `ProductHomeView.vue` 改为场景首页；首页不加载原有山水背景图片。其他业务页面继续使用原有布局。
- 造物阁 → `/generate`；藏品台 → `/library`；知物亭 → `/knowledge`；云间书案 → `/workspace`。右下功能导航提供全部主要入口。
- 点击铃铛放飞灯笼，点击水池产生涟漪；实际场景物体和地点标签均支持点击。拖动不会误触跳转。地点选择先聚焦并显示说明，再进入对应业务页。

页面的地形、建筑、云和远山都在同一个 Three.js 场景中。文字与导航保留为可读、可键盘操作的 HTML 界面。

## 展示资源

主楼来自本地任务 #33 的古建筑模型，网页使用独立简化副本，不修改原生成模型。桌面副本约 1.77 MB、81,405 三角面；手机副本约 0.86 MB、35,287 三角面。资源与出处保存在 `frontend/public/showcase/`。首页调整了网页副本的材质粗糙度和金属度显示，生成流程与原 GLB 不受影响。

## 性能与行为

手机采用轻量模型、较少云团并关闭场景阴影；限制渲染像素比。后台标签停止绘制，离开首页释放 WebGL 场景资源。支持暂停动态、系统减少动态效果偏好及 WebGL 不可用时的功能导航。云团限定为小范围往复运动，避免长时间停留后漂入主体。手机全景相机已拉远，以显示两侧小岛。
