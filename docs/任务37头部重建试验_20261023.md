# 任务37：第二轮头部重建试验，外观验收失败

## 结论

本轮未完成用户要求的面部辨识度修复。没有发布新的 ModelRevision，没有替换原始模型，没有修改未来任务默认工作流。
原先 #3 投影试验继续保持失败标记。

## 实际执行

1. 从原照片截取头、颈、衣领，沿用原任务 alpha 逆变换，未用 AI 重绘人物。检测头部占画面高度超过80%。第一次构图试验误用 thumbnail 导致未放大，已主动中断并修正，未用于最终验收。
2. 当前提交内存余量不足以安全执行1024完整重建，采用512几何单独生成。Pixal3D当前没有512纹理权重，因此把几何与1024纹理分开执行。512带纹理请求在模型预检时失败，未进行有效采样。
3. 成功生成1874882面头部几何，保留原始版本；使用现有减面工具降至400000面，边界范围校验通过。无纹理检查显示眼镜细节、嘴部笑容比原全身生成更明显，但这不等于相似度验收通过。
4. 对新几何执行1024纹理生成，2048颜色图。采样完成，实际PBR渲染仍有眼镜重影、帽子/头发颜色斑块、皮肤问题，失败。
5. 使用几何阶段MoGe相机值（FOV 0.5266384510676052，distance 1.8547451496124268）验证原图着色。检查发现节点55会按alpha重裁切，故实际保存节点55输出head-confirmed.png，不能拿裁切前图配相机。
6. 即使改用实际中间输入，PBR视角下仍有颜色斑块和五官重影。此方案失败，不继续把投影当作有效人脸修复方案。
