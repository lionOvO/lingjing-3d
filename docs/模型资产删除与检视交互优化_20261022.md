# 模型资产删除与检视交互优化（2026-10-22）

## 用户操作

- 模型资产卡片新增“删除”；工具栏新增“批量删除”，勾选后可跨页选择、“全选本页”、清空选择，再统一移入回收站。
- 删除需要确认，可到同页的“回收站”恢复。此操作只隐藏资产列表中的作品，保留模型文件、名称、标签、项目、修复版本和生成记录，不释放文件存储空间。项目历史仍能查看模型。
- 检视默认直接支持左键旋转视角、右键/中键或 Shift＋左键平移、滚轮缩放，不需要编辑开关或切换旋转/平移模式。
- 需要改变模型摆放时，到底部“变换工具”开启三轴工具，单击模型显示手柄，再选择移动或旋转。变换与材质参数仅影响浏览器预览。
- 检视区使用不透明中性灰，网格默认关闭，保留网格按钮；可选深灰、较浅灰和透明棋盘格背景。白色光源取代带颜色的光源，降低材质判断的色偏。
- 默认取景拉近，按视口较窄的视场角适配包围球。修正原来相机方向向量未归一化导致模型偏小的问题；保留完整模型与旋转余量。
- 资产缩略图、检查修复和对比共用的 ThreePreview 同步使用中性灰、无网格的默认设置。
- 窄屏下简化重复的检视器标题区域，避免文字挤成竖排；修复旧的 CSS 隐藏自动旋转开关内部 span 的问题。

## 后端与持久化

- 新增 `studio_asset_trash` 表，以 `task_id` 为主键并记录 `deleted_at`。API 启动时通过现有 `Base.metadata.create_all` 创建新表，不修改原任务或资产表。
- `GET /api/v1/studio/assets` 默认排除回收站条目；`deleted=true` 查询回收站，过滤在分页前执行。
- `DELETE /api/v1/studio/assets/{task_id}` 移入回收站。
- `POST /api/v1/studio/assets/{task_id}/restore` 恢复资产。
- 删除和恢复沿用登录用户的任务归属校验，只接受其已完成且存在输出地址的任务。重复删除或恢复可安全调用。
- `useAssets` 增加回收站参数和请求版本保护，避免切换列表后旧请求覆盖新结果；删除后页码自动限制在有效范围内。
