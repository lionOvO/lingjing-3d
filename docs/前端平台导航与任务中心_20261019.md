# 前端平台导航与任务中心

日期：2026-10-19。目标：让灵境造物从单条生成流程，形成可持续使用的 3D 创作平台。

## 布局选择

采用左侧主导航、顶部位置提示和账号、内容内部生成步骤。左侧放工作台、图片生成 3D、项目与模型、任务中心、知识库。生成步骤继续放在生成页面顶部，模型的材质、灯光等工具保留在预览器内部。

保留原有深蓝与冷蓝配色，导航采用更紧凑的间距与文字，减少与模型画布争夺注意力。桌面侧栏 224px，可手动收起为 76px 图标栏并记住选择；中等宽度自动使用图标栏；手机使用可关闭抽屉。顶部不再重复主导航。

## 实际接入

- 新增 `/tasks` 任务中心。旧任务详情继续使用 `/tasks/:taskId`，已有项目和预览链接仍有效。
- 从当前登录账号的项目分页加载真实任务，最多同时请求五个项目。统计、搜索、状态筛选、列表分页和刷新均使用实际响应。
- 已完成记录可进入模型预览，失败记录可查看原诊断。不自动提交任何生成任务。
- 部分请求失败时明确标记只显示已加载记录，不把错误当成没有历史任务。
- 修正首页和项目列表未传用户筛选参数的问题，改为按当前账号分页读取全部项目。此项是前端数据范围修正，不代表已完成后端权限审计。
- 浏览器标题改为“灵境造物 · 3D 创作平台”。

验收时当前账号有 7 个项目，11 条任务记录，其中 3 条标记完成、8 条失败。部分失败来自此前链路调试。历史完成状态不等于本次对旧模型的几何和纹理质量重新验收；本次之前完整验证过的真实新生成模型为任务 28。

已有：图片生成、项目历史、任务轨迹、确定性质检、模型与材质预览、下载、知识库查询。导航过去只暴露四个入口，详细功能分散在生成步骤和项目中。

后续优先建议：

1. 资产库：以模型缩略图组织已完成作品，支持名称、标签、格式检索。

3. 生成预设：保存已验证参数与适用图片类型，明确本机支持的能力。
4. 针对现有质检失败项提供可执行的网格处理，再逐步扩展多视图和贴图编辑。

截至 2026-10-19，以上四项为建议，未添加空白菜单或冒充已经实现。
