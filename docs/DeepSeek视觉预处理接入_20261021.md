下方保留原图与生成输入对照，以及清楚的复核结论。「高级调整」默认折叠，包含自动/手动分割方式、智能辅助开关、识别详情、建议范围、预览底色、裁剪与锐化。高级选择不会自动重绘；更换分割方式后仍点击同一「自动抠图」入口。关闭智能辅助后按手动检查处理，不显示为 AI 通过；未启用视觉服务时默认通用分割。

## 已部署的能力

图片预处理页面新增 DeepSeek 辅助区，官方模型为 `DeepSeek-V4.1-Flash`，API 标识为 `deepseek-flash`。已通过官方 `/models` 实际鉴权确认该账号可用，输入类型包含 text/image。密钥只由 API 服务读取，不发送到浏览器，不写入记录或测试结果。

1. **识别主体与分割建议**：发送原始图片，返回主体类别、完整主体范围（百分比坐标）、必须保留及应排除的部分、风险和置信度。动漫角色建议 ISNet Anime，建筑、真人及物品建议 U2Net。建议会选择分割方式；裁剪范围需点击“应用建议保留范围”才应用，仍应人工对照原图。
2. **本机分离前景**：继续使用现有分割模型，保留原图 RGB。DeepSeek 不生成透明遮罩，也不重绘、补全或改变姿态。
3. **复核当前处理结果**：同时发送原图和真实导出的生成输入；透明区域合成灰底后送去复核，便于观察轮廓。返回 pass / fail / uncertain，列出缺失和背景残留。发现缺失/残留时，即使模型文字判为 pass，服务端也改为 fail；置信度低于 0.75 时不判通过。

启用 AI 辅助后，须对当前结果复核通过才能点击“确认此图用于生成”。更改构图、分割结果等会清除旧审核；异步结果与当前图片/渲染版本不一致时丢弃。可以显式选择“改为手动检查”，此模式不记录为 AI 复核通过。该限制是页面辅助流程，不是服务端生成接口的语义安全保证。

模型出错、密钥错误、额度不足、连接失败、返回内容不完整/字段不合要求，均显示失败，不生成假审核结果。原有 3D 生成器、采样参数、种子、透明输入契约不变；没有重新开启旧的“角色属性文字分析”链路，也没有自动发起 3D 任务。

## 配置与接口

在项目 `.env` 设置：

```dotenv
DEEPSEEK_API_KEY=本地填写
DEEPSEEK_BASE_URL=https://api.deepseek.com
DEEPSEEK_MODEL=deepseek-flash
```

`DEEPSEEK_PROXY` 可单独配置；Compose 默认使用现有 `HTTPS_PROXY`。本机 Docker 直连曾在 TLS 握手阶段超时，通过已有 `http://host.docker.internal:7897` 代理后真实调用成功。代理只用于该模型的出站请求，不影响 API 到数据库/对象存储等内部连接。

`.env` 由 Compose 解析；不要直接用 `docker run --env-file .env` 验证带引号的密钥，该命令会保留引号，导致与 Compose 不同的 401。未改写用户密钥。

- `GET /api/v1/studio/images/vision-status`：已鉴权用户查询配置状态，仅返回 configured / model。
- `POST /api/v1/studio/images/vision-preparation`：multipart 字段 image；可选 candidate。有 candidate 时复核，无 candidate 时识别主体。输入每张不超过 20MB / 2000 万像素，限 PNG/JPEG/WebP；送云端前等比缩至最长 1536px，转换 JPEG。返回包含输入 SHA256，便于追溯。
- DeepSeek 使用 OpenAI 兼容 Chat Completions、内联 base64 图片、JSON 输出，关闭 thinking；单次上限 2200 输出 token，90 秒超时，服务内最多两路并发，无自动重试扣费。

楼阁测试使用用户截图中左右预览区域裁出的低分辨率图，不能等同于原始建筑素材的全分辨率分割验收。证据保存于 `tmp/deepseek-preparation-20261021/`（不含 API 密钥）。
