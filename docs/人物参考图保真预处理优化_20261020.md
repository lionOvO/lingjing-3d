# 人物参考图保真预处理优化

日期：2026-10-20。项目：`D:\灵境造物`。

## 用户目标

预处理应让图片中的人物更适合图生 3D，不能将“变成白底或透明底”等同于优化完成。用户确认：默认保留人物，只优化构图、背景干扰和清晰度；改变姿态、重绘或补全被遮挡部位应是独立可选能力。

本次落地默认保真的输入整理。没有接入生成式重绘、姿态纠正或遮挡补全服务，也没有用未经验证的按钮冒充这些能力。

本记录替代《参考图预处理替代视觉分析_20261020.md》中第一版“进入第二步自动抠图”的默认策略。第一版已经完成的确认前不入队、输入快照、跳过额外视觉语言服务及 ComfyUI 不重复分割的链路继续保留。

## 当前处理策略

1. 选择图片后，调用本机 CPU 像素检查，读取 EXIF 方向、尺寸、透明轮廓、边缘背景颜色和边缘清晰度。该检查不依赖 ComfyUI、GPU 或视觉语言服务。
2. 原图已有透明区域时，按全部有效 alpha 像素的范围整理，保留分离的配饰；不会重新执行人物分割。
3. 背景颜色简单时，用与边缘相连的近色像素估计背景，取剩余像素的包围范围指导构图。估计轮廓仅指导裁剪与缩放，不会据此擦除原图像素；额外留出安全范围。浅色衣物、细配饰仍可能估计不准，页面明确提示，可关闭自动轮廓整理。
4. 背景复杂或估计不可靠时，保留整图供手动框选，不凭空推断人物轮廓。
5. 按原图比例居中，输出 1024×1024 PNG，默认每侧 8% 留白，可调整到 0–24%。保留背景时，新增画布使用边缘估计颜色；透明原图继续保留透明。不会拉伸人体。
6. 低分辨率、轮廓靠边、较小主体和局部边缘对比偏低会给出提示。这里只检查像素，不判断人数、人体姿态、遮挡或服装完整性；最终仍需对照原图确认。
7. 轻度锐化默认关闭。开启后只增强已有边缘，限制通道变化，并避开透明边界。放大和锐化不能恢复缺失细节。

## 可选去背景及确认

- 用户主动点击“预览去背景效果（可选）”才调用已有本机 U2Net 接口。处理后显示候选说明，必须核对头发、手脚、衣摆与饰物，可以随时切回原图整理。
- 没有透明轮廓时，禁用中性灰、白底、透明底切换，避免只改画布边框却让人误以为背景已清理。已有 alpha 或去背景候选可合成底色。
- 裁剪、留白、轮廓整理、底色和锐化变化会使旧确认失效。正在检查或更新预览时不能确认。
- 裁剪区域没有可见像素时不导出、不允许确认；修正范围后恢复。错误分为输入检查/去背景错误与渲染错误，避免修正裁剪后留下过时的错误信息。
- 可以明确选择“保留原图用于生成”。最终点击“确认并开始生成 3D”前，不创建生成任务。

## 输入追溯与链路

新增登录保护的 `POST /api/v1/studio/images/analyze-reference`，限制 20MB 和 2000 万像素，支持 PNG/JPEG/WEBP，拒绝不可读或完全透明的输入。

新版 `image_preparation.version=2` 记录策略（`preserve-character` / `foreground-preview`）、背景、是否已有/生成透明轮廓、裁剪、留白、锐化、实际源区域、目标画布位置、像素检查结果和复核提示。`mode=original` 表示直接保留原图。

原图与确认结果分开保存。任务继续设置 `input_preprocessed=true`、`vision_analysis=false`，将已确认图片传入本机 Pixal3D，保留用户选择的纹理、面数与 PBR 设置。生成适配器既有的确定性 RGB 转换和防止 ComfyUI 二次抠图逻辑不变。透明 PNG 在条件编码前仍按既有约定合成到黑色 RGB，MinIO 的原始确认 PNG 保留透明；界面输出不能被理解为生成器完全不做格式转换。
