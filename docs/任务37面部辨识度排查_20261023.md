# 任务 37：面部辨识度排查与局部恢复

## 外观验收更正：失败

用户实际产品 PBR 预览确认版本 #3 存在五官错位、眼镜重影和头发贴图混乱，不满足面部辨识度要求。已重命名为「失败试验·面部投影错位·请勿使用」，options.validation_status 标记 failed。原模型未覆盖。

此前仅凭 CPU 颜色诊断图得出“辨识度改善”的表述不成立，撤回该验收结论。数组一致、GLB 可解析和存储校验只能证明文件完整，不能证明外观修复成功。现有投影使用整体边界拟合，缺少面部关键点与实际透视相机的可靠对应，不能作为人脸修复方案继续默认推广。后文记录为失败实验历史，不代表有效修复。

## 结果与限制

保存为独立 ModelRevision #3「原图面部细节恢复·试验版」。原始任务、模型对象和质量评分未改动。
恢复了原图眉眼、眼镜颜色、鼻下胡须、笑容等颜色细节。正面辨识度改善，但眼镜边缘重影、鼻嘴几何误差和侧面失真仍然存在，**未达到完整的身份/脸型相似度验收**。
此版本为单个模型经人工检查的修复试验，不是已经解决通用人脸生成质量。没有接入默认流水线。

## 证据

- 原始照片 1086×1448；预处理图 1024×1024，脸仅约一百像素宽。
- 原始 GLB 271283 顶点、501901 三角面，颜色图 1024²。
- 同机位 CPU 颜色与无纹理诊断：眼镜在几何上明显过厚；鼻嘴轮廓也有偏差。纹理中的眼睛、嘴部与原图不同。因此不是单独加大导出面数或贴图尺寸就能解决。
- 预处理并未删除原图五官；原图确实带有鼻下黑色胡须，恢复时保留。

## 修复范围

`scripts/repair_face_reference.py`：用原始源图快照和预处理记录中的主体边界（287,11,757,1418）投影恢复可见头面部，烘焙到现有 UV，使用 4096² 画布容纳局部颜色。画布变大不等于生成了新的三维细节。背面维持生成纹理；边缘渐变，UV 空白接缝扩边。几何位置、三角索引、UV、法线逐数组校验不变。

脚本含针对本模型归一化尺寸的人工审核区域与正面相机假设，**不能直接批量应用于其它人物**。不额外生成照片，不更换身份，不声称几何已修好。

`scripts/inspect_face_surface.py`：同一物理裁切区域渲染颜色/无纹理对照，另检查 25° 侧视角。属于诊断渲染，不等同于产品预览器的 PBR 光照。

## 验证

- 导出模型重新解析有效，面数保持 501901。
- 位置、索引、UV、法线保持一致。
- 对象存储上传下载 SHA256 一致，原始模型引用不变。
- 正面及 25° 渲染已人工检查；眼镜残影和侧面误差仍未通过外观验收。
- 证据：`tmp/face-quality-20261023/` 中 before、after、angle、clay、comparison PNG 及 GLB。

## 下一阶段所需工作

需要头部局部几何重建及眼镜分离，而不是继续叠加投影补丁。应采用带身份/人脸关键点约束的重建方法，并检查与身体的接缝；最好提供真实面部侧视图，降低被遮挡形状的不确定性。当前通用单图 Pixal3D 链路尚未实现这一能力，不能把局部纹理改善算作完整修复。
