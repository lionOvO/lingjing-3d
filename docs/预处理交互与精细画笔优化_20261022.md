# 参考图预处理交互与精细画笔优化（2026-10-22）

本次解决按钮拥挤、确认后仍需二次提交、画笔无法细修的问题。沿用现有山水背景和蓝色面板，不改变图生 3D 引擎与生成参数。

## 操作流程

1. 上传与配置：选择图片、设置生成参数，点击“下一步：预处理参考图”。移除上传区域内重复的图片编辑器，以及流程顶部重复的下一步按钮。
2. 参考图预处理：点击“自动抠图”，随后对照原图。模型、框选、构图和预览底色收进“更多设置”；下载图片保留为预览旁的辅助操作。
3. 部件缺失时打开“精细修补”。“完成修补，返回预览”保存原始分辨率的透明像素，并扩大裁剪范围以保留恢复的部件。重新进行 AI 完整性检查明确标为可选；人工确认集中在底部提交区域。
4. 页面只保留一个主提交入口：“确认图片并开始生成 3D”。点击后直接上传并创建任务，成功后进入“生成与质检”；失败原因显示在入口旁，保留修补结果和参数，可直接重试。
5. “使用原图直接生成”是独立的备用路径。复杂背景仍需确认风险，取消不提交；接受后直接使用原图创建任务。

独立的“参考图处理”工具页仍先带图前往生成设置，不会直接提交 GPU 任务。

## 精细修补工具

- 独立对话框：画布随窗口适配，底部完成和放弃按钮固定在窗口内，避免细长图片把操作挤出屏幕。
- 画笔直径按原图像素计，支持 1–200 px，数字输入、滑块以及 1 / 4 / 12 / 32 px 快捷选择。
- 圆形与方形笔刷；实际光标随缩放显示对应范围。1 px 笔刷对齐像素中心，避免在非整数缩放时无法命中细节。
- 缩放支持适合窗口、25%–800% 预设、放大/缩小按钮及 Ctrl + 滚轮；移动画布可用移动工具、空格或鼠标中键。
- 恢复 B、擦除 E、移动 H、方括号调整大小、Ctrl+Z 撤销和 Ctrl+Shift+Z / Ctrl+Y 重做。输入框内不拦截文字编辑快捷键。
- 历史快照按 64 MB 上限保留，超大图片至少保留一个步骤；连续涂抹只更新经过的画布区域。
- 恢复复制原图 RGBA，擦除只改透明度，不生成新内容。全部擦空时阻止保存并提示撤销。

预览底色仅改变显示，切换底色不再清空人工确认，也不会将白色背景写入透明 PNG。
