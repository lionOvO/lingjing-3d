# 参考图裁剪交互调整（2026-10-26）

## 目的与原因
裁剪滑块与图片预览分隔过远，且原实现把 rendering 纳入所有控件的禁用条件：每次滑块输入立即开始预览更新，并禁用滑块，打断连续拖动。每次更新还会重新解码原图、扫描像素和导出 PNG。

## 实现
- 修改 frontend/src/components/ImagePreparation.vue，将原图、生成输入、裁剪与构图设置放在同一工作区。宽屏右侧为设置面板；较窄屏幕设置紧跟图片。高级设置仅保留分割方式与智能识别说明，去掉重复的重置入口。
- 独立 controlsLocked 与 working：图像导出期间允许继续操作滑块；分割、识别、修补和提交期间仍保护输入；最终图片未准备好时仍禁止提交。
- 按源图缓存解码结果与最大边 512 的预览源；requestAnimationFrame 合并输入，绘制 384 的轻量构图预览。停止输入 250ms 后用原图重新计算精确范围并导出 1024×1024 PNG，提交文件和范围元数据保持原精度。
- 用版本号丢弃过时的异步导出；更换源图清除解码缓存；卸载时清理定时器与动画帧。预览更新提示缩为角标，不再遮住图片。
