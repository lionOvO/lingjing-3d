## 功能范围与实现边界

需求：实时显示上传进度、速度、剩余时间

当前边界：本地上传字节百分比可用；速度、剩余时间与 URL 拉取进度未实现。

图中无“设计”标记的是当前源码行为；标有“[设计]”及虚线/设计分支的部分是尚未落地的需求补充。

关键差异与限制：字节发送达到 100% 仍需等待服务端校验和存储完成；URL 模式只在 API 成功后设置 100%。

## 时序图

```mermaid
sequenceDiagram

    U->>F: 提交本地图片上传
    F->>F: busy=true，uploadProgress=0
    F->>A: POST /api/v1/uploads：FormData
    loop 浏览器产生上传进度事件
      B->>F: Axios onUploadProgress：loaded、total
      F->>F: 有 total 时计算 round(loaded / total * 100)
      F->>U: 更新上传百分比
    end
    A->>S: 校验图片并持久化
    alt 存储成功
      S-->>A: 返回对象与 URL
      A-->>F: 201 UploadResponse
      F->>F: 缓存 URL 并将进度设为 100
      F->>U: 继续项目和任务创建
    else 不满足或处理失败
      A-->>F: 422 校验或存储失败；前端解除 busy 并保留错误
      F->>U: 展示错误并结束本次操作；允许用户修正后重试
    end
  else 需求设计补充路径（尚未实现，非当前实际调用）
    B->>F: [设计] 采样 loaded 与时间戳
    F->>F: [设计] 计算速度和预计剩余时间；未知 total 时展示不定进度
    F->>U: [设计] 展示百分比、速度、剩余时间与服务端处理状态
  end
```

## 异常与结束条件

图内列出了该功能的关键校验、失败或降级路径。实际经过 FastAPI 的请求还可能返回 422 参数错误、409 数据冲突、503 数据库暂不可用或 500 未预期错误；前端经 Axios 的请求会显示统一错误，401 会清理登录状态。浏览器直连文件、WebSocket 和纯本地操作不经过同一个 Axios 错误拦截器。

需求验收目标（来自 PRD，不代表本次已验证达标）：进度更新频率 >= 2 次/秒
