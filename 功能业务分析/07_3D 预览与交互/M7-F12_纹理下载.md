## 功能范围与实现边界

需求：可打开 texture_urls 中的独立纹理；嵌入 GLB 纹理没有独立提取接口。

当前边界：可打开 texture_urls 中的独立纹理；嵌入 GLB 纹理没有独立提取接口。

图中无“设计”标记的是当前源码行为；标有“[设计]”及虚线/设计分支的部分是尚未落地的需求补充。

关键差异与限制：纹理直连原 URL，没有同源纹理代理；依赖 URL 可达性。GLB 内嵌材质仍可随模型下载，但当前不能单独解包导出。

## 时序图

```mermaid
sequenceDiagram
  autonumber
  actor U as 用户
  participant F as 前端页面与 Pinia
  participant B as 浏览器与本地缓存

  participant D as 关系数据库
  participant X as 外部服务（图片、纹理或身份）
  U->>F: 打开模型预览的纹理列表
  F->>A: GET /api/v1/tasks/{id}：请求指定任务
  A->>D: 按 task_id 读取 generation_tasks
  D-->>A: 返回任务状态、分析、参数、结果地址
  A-->>F: 200 TaskRead；Pinia 与最近任务缓存更新
  F->>F: textures=task.texture_urls；解析 URL 文件名
  alt 存在独立纹理 URL
    F->>U: 展示各纹理条目
    U->>F: 选择下载纹理
    F->>B: window.open(texture_url, _blank, noopener)
    B->>X: 直接 GET 纹理 URL
    X-->>B: 返回图片或外部错误
    B->>U: 显示或保存纹理
  else texture_urls 为空
    F->>U: 显示暂无独立纹理，不伪造下载项
  end
```

## 异常与结束条件

图内列出了该功能的关键校验、失败或降级路径。实际经过 FastAPI 的请求还可能返回 422 参数错误、409 数据冲突、503 数据库暂不可用或 500 未预期错误；前端经 Axios 的请求会显示统一错误，401 会清理登录状态。浏览器直连文件、WebSocket 和纯本地操作不经过同一个 Axios 错误拦截器。
