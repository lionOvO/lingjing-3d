## 功能范围与实现边界

需求：线框/实体/材质三种模式切换

当前边界：材质、实体和线框显示可用；法线模式为样式近似。

图中无“设计”标记的是当前源码行为；标有“[设计]”及虚线/设计分支的部分是尚未落地的需求补充。

关键差异与限制：normals 没有替换为 MeshNormalMaterial，不能宣称是真实法线颜色可视化。

## 参与方、调用与数据

U=用户、F=前端页面与 Pinia、V=前端 Three.js 预览器、A=后端 FastAPI、D=关系数据库、S=MinIO 对象存储。

输入、输出与存储由下列两张图中的箭头逐步标注。`A` 表示 FastAPI；`W` 表示 Worker/Agent；两者属于不同进程。图中 `F → F`、`V → V` 表示前端内部处理，`W → W` 表示后端内部处理。

涉及的现有接口或复用边界（设计路径另见图中标记）：

- `GET /api/v1/tasks/{id}`
- `GET /api/v1/models/{id}/preview`
- `GET /api/v1/models/{id}/content`

## 时序图

```mermaid
sequenceDiagram
  autonumber
  actor U as 用户
  participant F as 前端页面与 Pinia
  participant V as 前端 Three.js 预览器
  participant A as 后端 FastAPI
  participant D as 关系数据库
  participant S as MinIO 对象存储
  U->>F: 打开已有模型预览
  F->>A: GET /api/v1/tasks/{id}：请求指定任务
  A->>D: 按 task_id 读取 generation_tasks
  D-->>A: 返回任务状态、分析、参数、结果地址
  A-->>F: 200 TaskRead；Pinia 与最近任务缓存更新
  alt 任务 completed 且已有 output_model_url
    F->>A: GET /api/v1/models/{id}/preview
    A->>D: 读取输出地址与 _artifact_object_name
    D-->>A: 返回模型对象索引
    A-->>F: 200：download_url、output_format
    F->>F: 将内部 API 绝对地址改成前端网关同源路径
    F->>V: 传入 modelUrl 与 modelFormat
    alt GLB 或 GLTF 可预览
      V->>A: GLTFLoader GET /api/v1/models/{id}/content
      A->>S: get_object：读取模型二进制与内容类型
      S-->>A: 模型文件字节
      A-->>V: 200：文件字节与缓存头
      V->>V: 解析场景、释放旧资源、应用材质并适配相机
      V->>F: loaded 或 error 事件
    else OBJ、FBX、STL 或不支持格式
      V->>F: 提示当前仅支持 GLB / GLTF，结束加载
    end
  else 任务未完成或无结果地址
    F->>U: 显示未生成完成或失败状态；不请求模型文件
  end
  alt 模型已成功加载
    U->>F: 切换 material、solid、wireframe 或 normals
    F->>V: applyMaterials：设置 wireframe、材质颜色、粗糙度和 flatShading
    V->>V: 更新本地场景并渲染下一帧
    V->>U: 呈现当前预览效果
    Note over V: 此预览操作在浏览器内完成，不发起保存接口，不修改服务端原模型。normals 没有替换为 MeshNormalMaterial，不能宣称是真实法线颜色可视化。
  else 模型未加载或加载失败
    F->>U: 先完成模型加载或处理加载错误，再执行此操作
  end
```

## 异常与结束条件

图内列出了该功能的关键校验、失败或降级路径。实际经过 FastAPI 的请求还可能返回 422 参数错误、409 数据冲突、503 数据库暂不可用或 500 未预期错误；前端经 Axios 的请求会显示统一错误，401 会清理登录状态。浏览器直连文件、WebSocket 和纯本地操作不经过同一个 Axios 错误拦截器。

需求验收目标（来自 PRD，不代表本次已验证达标）：切换响应 < 500ms
