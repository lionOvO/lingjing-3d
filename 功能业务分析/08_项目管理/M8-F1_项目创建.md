## 功能范围与实现边界

需求：创建新项目，设置名称、描述、类型

当前边界：生成入口自动创建项目，已有项目可更新参考图并新增任务。

图中无“设计”标记的是当前源码行为；标有“[设计]”及虚线/设计分支的部分是尚未落地的需求补充。

关键差异与限制：当前生成页使用自动名称；API 支持自定义名称和描述，但没有独立创建项目表单。项目保存与任务创建是多个请求，不是一个跨请求原子事务。

## 时序图

```mermaid
sequenceDiagram
  autonumber
  actor U as 用户
  participant F as 前端页面与 Pinia
  participant A as 后端 FastAPI
  participant D as 关系数据库
  U->>F: 选择图片、项目类型并点击生成
  F->>A: 上传图片，取得 source URL
  A-->>F: 返回图片 URL
  alt 带有效 projectId
    F->>A: PATCH /api/v1/projects/{id}：source_image_url
    A->>D: 更新现有项目参考图
  else 无 projectId
    F->>A: POST /api/v1/projects：user_id、自动名称、description、project_type、源图
    A->>D: 确认用户存在后创建项目
  end
  alt 项目保存成功
    D-->>A: 返回项目实体
    A-->>F: 新建返回 201，更新返回 200 ProjectRead
    F->>A: POST /api/v1/tasks：project_id
    A->>D: 任务与项目关联
    A-->>F: 201 TaskRead
    F->>U: 进入该项目的新工作流
  else 不满足或处理失败
    A-->>F: 422 参数错误、404 资源不存在或 503 服务不可用
    F->>U: 展示错误并结束本次操作；允许用户修正后重试
  end
```

## 异常与结束条件

图内列出了该功能的关键校验、失败或降级路径。实际经过 FastAPI 的请求还可能返回 422 参数错误、409 数据冲突、503 数据库暂不可用或 500 未预期错误；前端经 Axios 的请求会显示统一错误，401 会清理登录状态。浏览器直连文件、WebSocket 和纯本地操作不经过同一个 Axios 错误拦截器。

需求验收目标（来自 PRD，不代表本次已验证达标）：创建响应 < 1s
